## ✨ Overview
A high-performance, visually stunning developer portfolio built with a focus on **premium aesthetics** and **smooth user experience**. This portfolio showcases my journey as a B.Tech CSBS student, specializing in Java, DSA, and Full-Stack development.

### 🎨 Design Philosophy
- **Amethyst Glow Theme**: A deep purple and ice blue palette for a modern, high-tech feel.
- **Glassmorphism**: High-intensity glass effects with backdrop filters and subtle borders.
- **Fluid Animations**: Custom reveal-on-scroll animations and interactive UI components.
- **Responsive Mastery**: Fully optimized for mobile, tablet, and desktop devices.

---

## 🛠️ Tech Stack
- **Frontend**: HTML5, Vanilla CSS3, JavaScript (ES6+)
- **Icons**: Font Awesome 6.4.0
- **Typography**: Google Fonts (Outfit, Syne, Plus Jakarta Sans)
- **Deployment**: Vercel

---

## 🌟 Key Features
- **Hero Section**: Dynamic typing effect and parallax-ready background blobs.
- **Interactive About Card**: Premium glass card with quote highlights and hover states.
- **Educational Timeline**: Vertical journey tracker with achievement scores.
- **Skill Grid**: Categorized technical mastery with zoom-in reveal effects.
- **Project Showcases**: Hover-animated cards with deep links to GitHub.
- **Contact Integration**: One-click connect via Email, LinkedIn, and Phone.
- **Custom Cursor**: A personalized dot cursor that tracks movement with a glow effect.
